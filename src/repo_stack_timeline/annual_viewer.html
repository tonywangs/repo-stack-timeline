What the samples show

Chalk goes from two root runtime declarations in 2020 to zero in 2021. Koa's count falls from 24 in 2019 to 18 in 2025. Flask adds a blinker declaration between the 2022 and 2023 samples.

Coverage matters: Python markupsafe stays at 50% in the available sample between the endpoints (1/2 → 2/4), but rises from 50% to 100% in the fixed sample (1/2 → 2/2). Use the sample selector below to inspect that difference.

Scope and reproduction

Purposeful convenience sample: Flask, Click, Jinja and ItsDangerous from Pallets; Express, Koa, Chalk and Commander from JavaScript. Shared governance and survival bias prevent population inference. Only root runtime declarations are included; build, development, optional, peer and transitive dependencies are excluded. Markers are preserved but not evaluated.

Snapshots follow the frozen current default branch's first-parent lineage. They can include unreleased development and are not historical default-branch or stable-release reconstructions. Annual sampling misses changes reversed within the year.

Run offline with Python 3.11+: python3 scripts/annual_report.py --output /tmp/annual-trends. Open the generated index.html. The report is deterministic, uses no external assets, and verifies frozen Git object and file hashes. Full history selection can be audited separately using the acquisition script.
